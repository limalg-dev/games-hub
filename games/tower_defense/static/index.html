Como Jogar

  • Objetivo: Defenda a colônia (final do caminho) dos invasores
  • Torres: Selecione um tipo, clique numa célula verde (construível). Clique numa torre existente para upgrade/sell
  • Navegação: 🖱️ Scroll = Zoom • Botão do meio/direito + arrastar = Mover câmera • Minimap = Clique para navegar
  • Inimigos: 🪰Fly (rápido) • 🏃Sprinter (muito rápido) • 🪲Beetle (blindado) • 🦟Sky Bug (balanceado) • 🛡️Tank (tanque) • 💀Boss (chefão!)
  • Economia: +5% juros por onda sobre suas economias
  • Mapa: Slots verdes = construível • Trilha marrom = caminho das formigas • Obstáculos = bloqueado
  • Atalhos: Espaço = Pausar/Retomar • Q = Chuva de Ácido • E = Névoa Congelante • Esc = Desselecionar
  • Poderes: 🧪 Chuva de Ácido [Q] = AoE click-to-target • ❄️ Névoa Congelante [E] = Congela todos
  • Torres: Clique numa torre para ver Prioridade de Alvo e Especializações L4 (Nível 3+)
